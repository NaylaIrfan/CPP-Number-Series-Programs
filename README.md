# C++ Number Series Programs

## About the Project
This repository contains beginner-friendly C++ programs for calculating the sum of different number series. It helps beginners understand loops, arithmetic operations, and series summation.

## Programs Included

1. **Sum of Natural Numbers** – Calculates the sum of natural numbers from 1 to 12.
2. **Sum of Squares** – Calculates the sum of squares of natural numbers from 1 to 12.
3. **Sum of Consecutive Integers** – Calculates the sum of integers from 5 to 8.
4. **Sum of Consecutive Squares** – Calculates the sum of squares of integers from 5 to 8.

## Technologies Used
- C++
- For loops
- Arithmetic operators
- Basic input and output

## How to Run

1. Download or clone this repository.
2. Open a `.cpp` file in a C++ compiler or IDE.
3. Compile and run the program.

Example using g++:

```bash
g++ 01_sum_natural_numbers.cpp -o series
```

Run on Windows:

```bash
series.exe
```

## Learning Objectives
- Understand number series in programming.
- Use loops to calculate sums.
- Perform square calculations using multiplication.
- Improve basic C++ programming skills.

## Conclusion
These programs are designed for beginners who want to practice loops and mathematical series in C++.
